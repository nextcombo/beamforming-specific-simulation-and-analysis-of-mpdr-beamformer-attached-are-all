# Beamforming - Specific Simulation and Analysis of MPDR Beamformer [Attached are all MATLAB codes]

Simulate the MPDR beamforming algorithm using an equidistant line array model and compare the implementation effects of SMI (Sample Covariance Matrix Inversion method) with SISP (Signal Projection Subspace method).
Line Array Signal Model Construction Assumptions:
- Bandwidth, far field, plane wave; ignoring the DDC and BP module group time delay differences among elements; ignoring the amplitude and phase differences of far field signals arriving at different elements.
Construction of MPDR Beamformer:
Conclusions on Applicable Scenarios and Limitations:
- Suitable for scenarios with prior information about the desired signal direction and carrier frequency, but SMI and SISP will "mislabel" high signal-to-noise ratio situations; under low signal-to-noise ratio or low dry noise ratio, SISP's interference subspace estimation is inaccurate. Both are suitable for pulse radars that require accumulation of echoes with low single-pulse energy.
Coherent Interference Handling:
- SMI and SISP have no capability for coherent interference handling, and simulations through setting variable frequencies and adding additional phase noise to decouple.
Extended Directions:
- Use continuous update gradient descent algorithm instead of batch processing; extend line array model to planar circular array; study coherent interference issues.

L = 16;% Array of elements, l = 0:L-1; K = 1024;% Fast Fourier Transform (FFT) k = 0:(K-1); j = sqrt(-1);% Construct complex Gaussian white noise power = 1;% Noise power sigma = sqrt(power/2);% Standard deviation noise = sigma.*((randn(L,K) + 1j*randn(L,K)));%Normalize the noise power. Construct the thermal noise at K sampling moments on each sensor. Construct signals with interference. Amplitude, Frequency Components Theta_s = [-50 -10 10 50] /180 * pi; mean_num = 1; % Expected signal number. The rest are interferences, snr_inr = [17 10 10 10]; % unit db, As the first angle is expected, Amp_s = sqrt(10.^(snr_inr/10)); % Calculated from signal-to-noise ratio and dry-noise ratio, amplitude f = [3E9 4E9 5E9 6E9];% Signal and interference frequency fs = 100e6; %Problem: The relationship between sampling frequency and signal carrier frequency c = 3e8; lambda = c ./ f; %Problem: Whether the performance is affected when the signal and interference frequencies are unknown d = min(lambda)/4; % Elementary interval M = length(Theta_s); % Signal and interference count S = zeros(M, K); % Sample M signals and interference K times, A = zeros(L, M);for m = 1:M%     S(m, :) = Amp_s(m) .* exp( (1j*2*pi*f(m)/fs) * k ); % When the frequency is the same. Coherent interference S(m, :) = Amp_s(m) .* exp( 1j*((2*pi*f(m)/fs) * k + randn(1, K))); % When the frequency is the same. Constructing non-coherent interference with phase perturbation m) = exp(1j*2*pi*d*sin(Theta_s(m))/lambda(m) * l);% Generate noisy MPDR with SMIX = A*S + noise; % X = A*S; % Noise-free Rxx = (X * X')/K; % W_mvdr = inv(Rxx)*A(:,mean_num)/(A(:,mean_num)'* inv(Rxx) * A(:,mean_num)); % With the first angle as the desired signal and the rest as interference W_smi = Rxx\A(:,mean_num); % With the first angle as the desired signal and the rest as interference %% SISP_MVDR[U,D] = eig(Rxx); Us = U(:,L-M+1:L);% Extract the main feature vector Ds = D(L-M+1:L, L-M+1:L); % Extracting the main eigenvalue W_sisp = Us * inv(Ds) * Us' * A(:, mean_num); %% Directional pattern construction: theta_num = 3601; % Angle search number theta_search = linspace(-pi/2, pi/2, theta_num); y = zeros(1, theta_num); y_sisp = zeros(1, theta_num);for n = 1:theta_num    aaa = exp(1j * 2 * pi * d * sin(theta_search(n))/lambda(mean_num) * l );    y(n) = W_smi' *  aaa.';    y_sisp(n) = W_sisp' *  aaa.';endydB = 10*log10(abs(y)/max(abs(y)));ydB_sisp = 10*log10(abs(y_sisp)/max(abs(y_sisp)));% y_max = max(max(abs(y)),max(abs(y_sisp)));% ydB = 10*log10(abs(y)/y_max);% ydB_sisp = 10*log10(abs(y_sisp)/y_max);%
Plot 1: Comparison of Beam Patterns between SMI and SISP under Different Signal-to-Noise Ratios figure('name','Beam Direction Plot','color',[1,1,1]);hold onplot(theta_search * 180/pi,ydB,'color','b','linestyle','-','linewidth',1);plot(theta_search * 180/pi,ydB_sisp,'color','r','linestyle','-','linewidth',1);legend('SMI','SISP')% title('ISNR:-10dB')% title('ISNR:1dB')% title('ISNR:10dB')% title('ISNR:13dB')title('ISNR:17dB')% title('ISNR:20dB')hold off;grid onxlim([-90,90]);ylim([-40,0]);set(gca,'xtick',-90:10:90);set(gca, 'FontName', 'Times New Roman', 'FontSize', 10.5); xlabel('Direction of Arrival of the Signal (Degree)', 'FontSize', 10.5); ylabel('Magnitude Response (dB)', 'FontSize', 10.5); %% Output the SNR construction. Compare the output SNR of the aforementioned algorithms under different input SNRs in SMI and SISP, to avoid variable naming by adding an underscore before the variable name: ISNR = -30:1:30;OSNR_smi = zeros(1, length(ISNR)); G_smi = zeros(1, length(ISNR)); OSNR_sisp = zeros(1, length(ISNR)); G_sisp = zeros(1, length(ISNR)); for i=1:length(ISNR)    snr_inr_var = [ISNR(i) 10 10 10]; % unit db, Expectation signal at the first angle: Amp_s_var = sqrt(10.^(snr_inr_var/10));% Calculate the amplitude of signal and noise from signal-to-noise ratio and dry-noise ratio K); % Take K samples for each of M signals and interferences :) = Amp_s(m) .* exp( (1j*2*pi*f(m)/fs) * k ); % When the frequency is the same. Coherent interference S_var(m, :) = Amp_s_var(m) .* exp( 1j*((2*pi*f(m)/fs) * k + randn(1, K)));% When the frequency is the same. Constructing non-coherent interference using phase perturbation. Rxx_var = (X_var * X_var')/K; W_smi_var = Rxx_var\A(:, mean_num); % Expecting the first angle as the desired signal. The rest are interferences. G_smi(i) = 10 * log10(abs((W_smi_var'* A(:, mean_num))/(W_smi_var' * W_smi_var)));%Gain %%SISP_MVDR    [U_var, D_var] = eig(Rxx_var); Us_var = U_var(:, L-M+1:L); % Extract the principal feature vector Ds_var = D_var(L-M+1:L, L-M+1:L); % Extracting the main eigenvalue W_sisp_var = Us_var * inv(Ds_var) * Us_var'* A(:, mean_num);G_sisp(i) = 10*log10(abs((W_sisp_var'* A(:, mean_num))/(W_sisp_var' * W_sisp_var))); OSNR_sisp(i) = ISNR(i)+G_sisp(i); end%% Plot 2 SMI and SISP output signal-to-noise ratio comparison under different input signal-to-noise ratios figure('name', 'OSNR', 'color', [1, 1, 1]);hold onplot(ISNR,OSNR_smi,'color','b','linestyle','-','linewidth',1);plot(ISNR,OSNR_sisp,'color','r','linestyle','-','linewidth',1);legend('SMI','SISP')title('OSNR')hold off;grid onset(gca,'FontName','Times New Roman','FontSize',10.5);xlabel('ISNR(dB)','FontSize',10.5);ylabel('OSNR(dB)','FontSize',10.5);figure('name','Gain','color',[1,1,1]);hold onplot(ISNR,G_smi,'color','b','linestyle','-','linewidth',1);plot(ISNR,G_sisp,'color','r','linestyle','-','linewidth',1);legend('SMI','SISP')title('Gain')hold off;grid onset(gca,'FontName','Times New Roman','FontSize',10.5);xlabel('ISNR(dB)','FontSize',10.5);ylabel('G(dB)','FontSize',10.5);\n
